# 직장생활 N분의 1

0살부터 태어나 자라고, 취업해서 회사생활을 하는 인생 시뮬레이션입니다.
처음 화면에서 두 버전 중 하나를 고릅니다.

- **v1 공공기관 편** (`v1/`): 같은 날 입사한 다섯 명 중 한 명으로 30년을 사는 공공기관 커리어 시뮬레이션
- **v2 회사생활 편** (`v2/`): 0살에 태어나 학교·대학·군대를 거쳐 취업하고, 회사에서 퇴직까지 사는 시뮬레이션

웹 텍스트 게임 '80억 분의 1'에서 영감을 받았습니다.

> **비공식 팬메이드입니다.** 실제 기관의 공식 자료가 아니며, 등장인물은 모두 랜덤으로 만든 가상 인물입니다.
> 인원·초봉·채용 구조는 공개된 채용 공고와 공공기관 공시 정보를 참고했고, 승진 연수·확률·이벤트는 추정입니다.

## 플레이 방법

설치나 서버 없이 루트의 `index.html`을 브라우저에서 열면 됩니다.

### v2 회사생활 편

1. **태어나기**를 누르면 성별, 집 형편, 지역, 형제가 확률로 정해집니다.
2. 유아기·초·중·고는 1년이 1턴, 졸업 후에는 한 학기가 1턴입니다. 초등학생부터는 선택지마다 오르내리는 스탯이 보입니다.
3. 학업·체력·사교·멘탈이 수능, 체대 입시, 학생회장, 취업 합격 가능성을 가릅니다. 어떤 활동을 했는지는 숨은 경험으로 남아 나중에 팀 배치에 영향을 줍니다.
4. 중학생부터 **부모님께 과외 부탁하기** 행동을 쓸 수 있습니다.
5. 대학, 군 복무(남자), 대학원, 알바·인턴, 교환학생을 거쳐 대기업·공기업·중견·IT기업·스타트업 중 한 곳에 지원합니다.
6. 합격하면 **회사생활 시작하기**로 넘어갑니다. 한 달이 1턴이고, v1의 사내 관계·자산·연애·육아가 그대로 이어집니다. 회사 종류마다 직급, 연봉, 업무 강도, 경쟁사와 업계 순위, 희망퇴직, 투자 유치·폐업·인수가 다릅니다.

`v2/work.html`은 `v1/index.html`을 바탕으로 `v2/tools/mkwork.py`가 만듭니다. v1을 고친 뒤에는 이 스크립트를 다시 돌립니다.

### v1 공공기관 편

1. 플레이 시간(약 30분 / 1시간 / 1시간 30분)을 고르고 **입사하기**를 누릅니다.
2. 입사 통지서에서 직렬, 고용형태, 배치 부서, 연고지가 확률과 함께 정해집니다. 커리어 목표를 고릅니다.
3. 한 달이 한 턴입니다. 대부분의 달은 그냥 지나가고, 가끔 선택창이 뜹니다.
4. 언제든 할 수 있는 것
   - **집중 항목**: 업무 / 자기계발 / 관계 / 건강
   - **행동**: 여행, 병원, 한턱, 학원, 연애, 집·차 구매, 반려동물 등
   - **자산 관리**: 주식 비중, 적금, 리츠, 오피스텔
   - **사내 관계**: 원장·실장·팀장과 점심, 조언, 선물, 아부
   - **동기 만나기**: 밥, 술·상담, 스터디
5. 정년퇴직, 이직, 계약 만료, 번아웃, 사직 등으로 끝나면 인사기록 최종본이 나옵니다.

진행 상황은 저장되지 않습니다. 새로고침하면 처음부터 다시 시작합니다.

## GitHub Pages로 배포하기

1. 저장소 **Settings → Pages**로 이동합니다.
2. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
3. 몇 분 뒤 `https://kimseokjun.github.io/80game/` 에서 플레이할 수 있습니다.
